TONG QUAN UNG DUNG MONEYMATE
============================

Tai lieu mo ta phien ban ma nguon hien tai cua MoneyMate. Frontend Flutter va
backend ASP.NET Core da duoc tich hop qua REST API; du lieu nghiep vu duoc luu
trong SQL Server. Khong nham tai lieu nay voi cac ban mo ta prototype cu.


1. MUC DICH VA PHAM VI
----------------------
MoneyMate ho tro quan ly thu chi ca nhan va mot so nghiep vu ho gia dinh:
ghi nhan giao dich, quan ly ngan sach, xem thong ke, quan ly nhom thanh vien.
Ung dung co cac tai khoan/giao dich ngan hang va vi dien tu mo phong de minh
hoa dong tien; khong dang nhap, ket noi hoac thuc hien giao dich tai chinh that.

Trang thai hien tai:
- Flutter dang dang nhap Firebase, goi REST API co xac thuc va tai giao dich/
  ngan sach tu backend SQL Server.
- Giao dich thu/chi thu cong, ngan sach, ho so va mot so thao tac ho gia dinh
  duoc xu ly qua API va luu tren SQL Server.
- Giao dich ngan hang/vi la du lieu demo do ung dung tao, nhung cac giao dich
  demo duoc luu tren backend de hien thi cung lich su thu chi.
- Man hinh loi moi thanh vien la prototype: loi moi chi nam trong bo nho cua
  man hinh, khong gui email va khong luu vao backend.
- Backend co API yeu cau va xu ly phe duyet chi; giao dien Flutter chua tich hop
  day du luong phe duyet nay.

3. CHUC NANG FRONTEND
---------------------
Ung dung su dung Flutter Material 3. Sau khi dang nhap, thanh dieu huong gom
sau muc:

1) Tong quan - app_frontend/lib/screens/home_screen.dart
   Hien thi tong thu, tong chi, so du tinh tu giao dich da tai, mot so giao
   dich gan day va cac ngan sach dang can chu y.

2) Giao dich - transactions_screen.dart, transaction_form_screen.dart
   Liet ke giao dich; tao, sua va xoa giao dich thu/chi. Bieu mau gom tieu de,
   so tien, danh muc, ngay va ghi chu; du lieu duoc gui den API va tai lai sau
   khi thao tac. Giao dich mo phong da dong bo khong cho sua.

3) Ngan sach - budget_screen.dart
   Tai danh sach va danh muc tu API; tao, sua va xoa ngan sach voi ten, han muc,
   chu ky, che do, uu tien, ngay bat dau/ket thuc va danh muc neu chon. Cac che
   do hien co gom "Du dinh" va "Dang thuc hien".

4) Thong ke - statistics_screen.dart
   Chon thang va nam de xem tong thu, chi, chenh lech, bieu do cot va chi tieu
   theo danh muc. Cac so lieu tren man hinh duoc tinh tu danh sach giao dich
   da tai vao ung dung.

5) Vi mo phong - bank_wallets_screen.dart, linked_flow_screen.dart,
   demo_transaction_bundle_screen.dart
   Hien thi cac nguon mau; cho phep tao tai khoan mo phong va nhieu giao dich
   thu/chi voi danh muc, so tien, ngay va ghi chu. Giao dich demo duoc luu qua
   API/SQL Server, co khoa idempotency cho tung dong de tranh tao trung khi
   gui lai. Man hinh dong tien loc theo thang, ngay va nguon. Khong ket noi
   ngan hang/vi that.

6) Ca nhan - profile_screen.dart, household_screen.dart
   Xem/cap nhat ten hien thi, dang xuat; tao nhom gia dinh, xem/thay doi thanh
   vien theo quyen, xem thong bao va danh dau da doc. Chu nhom co the huy nhom;
   lich su tai chinh duoc giu lai theo nghiep vu backend.

Man hinh invitations_screen.dart duoc mo tu khu vuc ho gia dinh nhung chi la
giao dien mo phong loi moi; khong nen mo ta no nhu mot tinh nang gui loi moi
hoat dong day du.

Xac thuc:
- Firebase Authentication ho tro dang ky/dang nhap bang email va mat khau,
  cung dang nhap Google (tuy cau hinh nen tang/Firebase).
- AuthGate theo doi trang thai dang nhap. Sau khi dang nhap, ung dung dong bo
  ho so qua /api/me va tai giao dich/ngan sach; neu bootstrap API that bai,
  man hinh hien canh bao.
- ApiClient lay Firebase ID token va gui trong cac request can dang nhap.

5. BACKEND/API
--------------
Project chinh: app_backend/app_backend.Api/app_backend.csproj
- ASP.NET Core Web API, .NET 8; SQL Server qua Entity Framework Core.
- Program.cs dang ky Firebase JWT bearer authentication, authorization,
  FinanceManagerDbContext, cac service nghiep vu va CORS.
- Swagger/UI duoc bat trong moi truong Development.
- CORS cho phep origin loopback; origin frontend ben ngoai loopback can duoc
  khai bao ro trong Cors:AllowedOrigins.

Controller va route chinh:
- MeController: /api/me - doc/cap nhat ho so va dong bo nguoi dung.
- TransactionsController: /api/transactions - doc/tao/sua/xoa giao dich.
- BudgetsController: /api/budgets - CRUD ngan sach.
- CategoriesController: /api/categories - lay danh muc.
- AccountsController: /api/accounts - thao tac tai khoan.
- StatisticsController: /api/statistics - truy van thong ke.
- HouseholdsController: /api/households - nhom, thanh vien, thong bao, huy
  nhom.
- ApprovalRequestsController: /api/approval-requests - xem yeu cau va phe
  duyet/tu choi.

Cac API nghiep vu duoc bao ve bang [Authorize] va can Firebase ID token hop le.
CurrentUserService dong bo/tra cuu nguoi dung; HouseholdAuthorizationService
kiem tra quyen thanh vien; TransactionService va ApprovalService xu ly nghiep vu
giao dich/phe duyet.


6. DATABASE VA MIGRATIONS
-------------------------
Database mac dinh: FINANCE_MANAGER (SQL Server).
DbContext: app_backend/app_backend.Api/Data/FinanceManagerDbContext.cs
Migrations: app_backend/app_backend.Api/Data/Migrations/

Migration hien co:
- 20261025064640_InitialCreate: schema ban dau.
- 20261025144100_AddHouseholdNotifications: bo sung thong bao ho gia dinh.

Database moi duoc tao/cap nhat bang EF Core:
    dotnet tool restore
    dotnet ef database update --project app_backend\app_backend.Api\app_backend.csproj

Script app_doc/SQLQuery1.sql la schema SQL legacy, khong phai quy trinh migration
chinh cho database moi. Khong chay InitialCreate truc tiep len database da tao
bang script cu neu chua baseline migration. Tren database legacy, chay
app_doc/SQLQuery2_HouseholdNotifications.sql de them bang thong bao neu chua co.

Bang nghiep vu chinh:
- Users: nguoi dung va Firebase UID.
- Households, HouseholdMembers: nhom, vai tro, trang thai va quyen thanh vien.
- Accounts: tai khoan ca nhan/nhom, gom ca nguon demo.
- Categories: danh muc thu/chi.
- Transactions, TransactionShares: giao dich va chia se giao dich.
- ApprovalRequests: yeu cau phe duyet.
- Budgets: ngan sach, chu ky, che do va uu tien.
- HouseholdNotifications: thong bao va thoi diem da doc.

Enum BudgetPeriod duoc dong bo giua Dart/C# va schema SQL:
0=Monthly, 1=Weekly, 2=Yearly. Khi thay doi entity/enum, tao migration moi;
neu van su dung script SQL legacy thi cap nhat script do tuong ung.


7. CAU HINH VA LENH PHAT TRIEN
------------------------------
Yeu cau:
- Flutter SDK voi Dart constraint ^3.9.2.
- .NET 8 SDK.
- SQL Server dang chay.
- Firebase project da cau hinh cac phuong thuc dang nhap can dung.

Frontend (chay tu app_frontend):
    flutter pub get
    flutter run -d chrome
    flutter analyze
    flutter test

Package chinh: fl_chart, http, firebase_core, firebase_auth, google_sign_in;
kiem thu va lint dung flutter_test va flutter_lints.

Backend (chay tu thu muc goc):
    dotnet restore app_backend\app_backend.Api\app_backend.csproj
    dotnet tool restore
    dotnet user-secrets set "ConnectionStrings:MoneyMate" "<connection-string>" --project app_backend\app_backend.Api\app_backend.csproj
    dotnet user-secrets set "Firebase:ProjectId" "<firebase-project-id>" --project app_backend\app_backend.Api\app_backend.csproj
    dotnet ef database update --project app_backend\app_backend.Api\app_backend.csproj
    dotnet run --project app_backend\app_backend.Api\app_backend.csproj --launch-profile http

Khong commit connection string hoac thong tin bi mat vao source code.
Profile http chay tai http://localhost:5265; Swagger Development tai
http://localhost:5265/swagger.

API_PORT co gia tri mac dinh 5265; vi du doi port:
    flutter run -d chrome --dart-define=API_PORT=6000

Co the cung cap URL day du, uu tien hon API_PORT:
    flutter run -d chrome --dart-define=API_BASE_URL=https://localhost:7149

Android emulator mac dinh su dung host 10.0.2.2. Thiet bi that can URL backend
co the truy cap tren mang va backend phai lang nghe tren giao dien mang phu hop.


8. KIEM THU, GIOI HAN VA HUONG PHAT TRIEN
-----------------------------------------
Test hien co:
- app_frontend/test/widget_test.dart co hai widget smoke test: hien thi man
  hinh dang nhap va cac phan chinh cua man hinh tong quan.
- Cac test nay khong thay the kiem thu API, Firebase, SQL Server, phan quyen
  ho gia dinh hoac kiem thu end-to-end.

Gioi han da biet:
- Chua co kiem thu end-to-end voi Firebase va SQL Server that trong moi
  truong; can cau hinh secrets va database de kiem tra runtime.
- Loi moi thanh vien la giao dien mo phong, chua gui email va chua luu API.
- Luong phe duyet chi co API backend nhung chua co giao dien Flutter hoan chinh.
- Tinh nang ngan hang/vi chi la mo phong, khong dong bo voi nha cung cap tai
  chinh.
- Widget test hien tai la smoke test, chua bao phu day du form va cac loi API.

Huong phat trien:
- Hoan thien luong loi moi/tham gia nhom va giao dien phe duyet chi.
- Bo sung kiem thu don vi, tich hop va end-to-end cho API, authentication va
  phan quyen.
- Hoan thien cau hinh trien khai, quan sat loi va tai lieu van hanh.

TONG QUAN UNG DUNG MONEYMATE / FINANCEMANAGER
=============================================

Tai lieu nay cap nhat theo cau truc workspace va ma nguon dang co. Ten hien thi
cua ung dung Flutter la MoneyMate; script SQL dat ten database FINANCE_MANAGER.


1. MUC DICH VA TINH TRANG TONG QUAN
-----------------------------------
MoneyMate la ung dung Flutter minh hoa quan ly thu chi ca nhan: ghi nhan giao
dich, lap ngan sach, xem thong ke va mo phong giao dich tu tai khoan ngan hang/
vi dien tu mau.

Hien tai:
- Frontend Flutter co giao dien va chuc nang demo; du lieu giao dich/ngan sach
  chi nam trong RAM, khong duoc luu sau khi dong ung dung.
- Frontend chua goi API backend.
- Backend ASP.NET Core da co project .NET 8, nhung phan dang duoc cau hinh de
  chay la MVC scaffold co Home/Privacy. Cac tep API/auth/data duoc de lai tu
  huong phat trien, chua duoc dang ky/noi vao luong chay hien tai.
- Cac tai khoan ngan hang va vi dien tu tren giao dien chi la du lieu mo phong
  phuc vu hoc tap; khong ket noi tai khoan tai chinh that.

4. TO CHUC MA NGUON FRONTEND

- AuthGate kiem tra trang thai Firebase; FinanceNavigation quan ly cac man hinh.

- api_budget_model.dart: DTO ngan sach tu backend; budget_model.dart la model

- MoneyMateBackend la singleton ChangeNotifier tai giao dich tu API va cung cap
  so du, tong thu/chi, chi tieu va thong ke cho cac man hinh.
- Giao dich thu/chi thu cong va giao dich mo phong duoc luu ben vung tren SQL
  Server qua REST API; ngan sach duoc quan ly truc tiep qua BudgetApiService.
- Vi demo chi la du lieu mo phong, khong ket noi ngan hang/vi that.
- ApiClient quan ly Firebase ID token, HTTP requests va loi API; ApiConfig cau
  hinh dia chi backend cho tung nen tang.

app_frontend/lib/screens/
- Moi tep chua man hinh nghiep vu tuong ung; cac man hinh doc/cap nhat state
  qua MoneyMateBackend.instance va lang nghe thay doi.

  luong import chinh; man hinh form dang dung la transaction_form_screen.dart.


5. BACKEND .NET VA CAC THANH PHAN API
-------------------------------------
Project:
- app_backend/app_backend.sln la solution; project
  app_backend/app_backend.Api/app_backend.csproj su dung ASP.NET Core/.NET 8,
  EF Core SQL Server va EF Core Design tooling.
- Program.cs dang ky Firebase JWT authentication, authorization, DbContext,
  CORS, cac service nghiep vu va REST/MVC routes.
- Controllers/ cung cap API cho tai khoan, danh muc, giao dich, ngan sach,
  thong ke, ho gia dinh, phe duyet va ho so nguoi dung.

Thanh phan nghiep vu va xac thuc:
- Auth/FirebaseAuthenticationHandler.cs: ma xu ly Bearer token Firebase va
  tao claim UID; API hien dang dang ky Firebase JWT Bearer authentication.
- DTOs/CreateTransactionRequest.cs: payload tao/cap nhat giao dich.
- services/HouseholdAuthorizationService.cs: logic kiem tra thanh vien/quyen
  ho gia dinh; TransactionService.cs co doan logic yeu cau duyet chi.
- Models/: Account, User, Household, HouseholdMember va Transaction; cac enum
  dinh nghia trong Enum.cs.
- DbContext va EF Core migrations da duoc tao; controllers/doc ghi cac model
  thong qua API.
- Cac service va model da duoc ket noi vao project API va kiem tra build.
- Connection string rieng theo may khong duoc luu trong appsettings; cung cap
  config moi truong qua User Secrets hoac bien moi truong.


6. MO HINH DU LIEU VA SQL
-------------------------
app_doc/SQLQuery1.sql la script bootstrap schema cu. Schema hien tai duoc quan
ly chinh bang EF Core migrations trong
app_backend/app_backend.Api/Data/Migrations/. Database moi co the tao/cap nhat
bang dotnet ef database update. Khong ap dung migration InitialCreate len
database da chay script cu neu chua baseline migrations.

Schema gom cac bang:
- Users: nguoi dung, Firebase UID, email, ten hien thi, trang thai.
- Households: nhom gia dinh, nguoi tao va nguong can duyet.
- HouseholdMembers: vai tro Owner/Admin/Member, trang thai va quyen thanh vien;
  SQL co unique index de mot nguoi chi nam trong mot household dang hoat dong.
- Accounts: tai khoan cua nguoi dung, co the thuoc household; ho tro cash,
  bank demo, e-wallet demo.
- Categories: danh muc thu/chi.
- Transactions: thu/chi/chuyen tien, nguoi tao, tai khoan, danh muc, visibility,
  approval status, xoa mem va rowversion.
- TransactionShares: chia se giao dich den nguoi dung duoc chon.
- ApprovalRequests: yeu cau phe duyet cho giao dich.
- Budgets: han muc theo household/nguoi tao/danh muc, chu ky, che do va uu tien.

Schema SQL co khoa ngoai, unique/check constraints va index cho giao dich.
Enum BudgetPeriod hien dang dong bo ve gia tri voi SQL: 0=Monthly, 1=Weekly,
2=Yearly. SQL va enum can duoc giu dong bo neu thay doi schema.


7. CAU HINH VA LENH PHAT TRIEN
------------------------------
Flutter:
- Dart SDK constraint: ^3.9.2 trong app_frontend/pubspec.yaml.
- Dependencies: Flutter SDK, cupertino_icons, fl_chart, http, Firebase Core/Auth,
  Google Sign-In; dev dependencies: flutter_test va flutter_lints.
- Thuc hien lenh tu thu muc app_frontend:
    flutter pub get
    flutter run
    flutter analyze
    flutter test
- Man hinh thong ke hien tai tu ve bieu do bang widget Flutter.

Backend:
- Mo app_backend/app_backend.sln bang Visual Studio hoac chay project
  app_backend/app_backend.Api/app_backend.csproj voi .NET 8 SDK.
- Properties/launchSettings.json co cac profile HTTP/HTTPS phuc vu chay local.
- Cau hinh ConnectionStrings:MoneyMate va Firebase:ProjectId qua User Secrets
  hoac bien moi truong; khong commit connection string rieng cua may.
- EF Core CLI duoc pin trong .config/dotnet-tools.json; chay dotnet tool restore
  truoc khi tao/ap dung migration.


8. TINH TRANG CAC HANG MUC CAN LAM
---------------------------------
Da hoan thanh:
- Ket noi Flutter voi REST API qua ApiClient va cac service theo nghiep vu;
  Firebase ID token duoc gui den backend, loi HTTP duoc chuyen thanh ApiException.
- Backend da dang ky Firebase JWT, EF Core SQL Server, entities/DbContext,
  dependency packages va controller API. Cac quan he FK duoc khai bao ro rang,
  khong tao shadow FK.
- Giao dich thu cong tao/sua/xoa va ngan sach duoc luu tren SQL Server qua API.
  Du lieu dong bo vi demo cung duoc luu ben vung va co tinh idempotent.
- Man hinh Ngan hang & vi dien tu cho phep nhap ten nguon tuy y va tao tai
  khoan mo phong kem nhieu giao dich thu/chi; moi dong giao dich co ma chong
  tao trung khi gui lai sau loi mot phan.
- Owner co the huy mem nhom; thanh vien duoc roi nhom, lich su tai chinh duoc
  giu lai va nhan thong bao trong ung dung.
- Test scaffold Counter da duoc thay bang widget smoke tests cho man hinh dang
  nhap va trang tong quan.
- BudgetPeriod trong Dart/C# va SQL dang dung cac gia tri 0=Monthly,
  1=Weekly, 2=Yearly.
- Connection string rieng theo may da duoc go bo khoi appsettings; su dung User
  Secrets/bien moi truong thay the.

Can luu y/kiem thu them:
- Widget test hien la smoke test, chua bao phu day du cac luong form, API,
  xac thuc va phan quyen.
- Chua chay kiem thu end-to-end voi Firebase va SQL Server thuc trong moi truong
  nay; can cau hinh User Secrets va database truoc khi danh gia runtime.
- Migration InitialCreate danh cho database moi. Database da tao bang
  app_doc/SQLQuery1.sql can duoc baseline migration rieng truoc khi chay
  dotnet ef database update.
- Migration AddHouseholdNotifications danh cho database moi. Database cu tao
  bang SQLQuery1.sql can chay app_doc/SQLQuery2_HouseholdNotifications.sql de
  them bang thong bao; khong chay InitialCreate truc tiep tren database nay.
- Khi thay doi entity/enum/schema, tao migration moi va cap nhat tai lieu/schema
  SQL legacy neu van con dung script do de bootstrap database.
